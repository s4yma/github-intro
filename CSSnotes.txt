*CSS--> Cascading style sheets
Codes of CSS is known as "Properties".
*CSS is of 3 types:-
1)Inline CSS
2)Internal CSS
3)External CSS 

*Inline CSS: This is a kind of CSS which is written inside a tag.

*Internal CSS: This is kind of CSS which written inside a HTML file.

*External CSS: This is a kind of CSS which is written by making a totally new CSS file.

*In Internal CSS, we call different functions(For ex:-body,h1,a,p,etc.) and add different features and upgradings to 
 it.

*When we write something by using "style" tag in "head", it is called Internal CSS.

*When we write internal css in the style tag, we will use "{}" after the name of the tag we're calling.

*When we write something by using "style" attribute  inside a "tag", it is called inline css.
